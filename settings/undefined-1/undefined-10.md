# 내용 검색 설정

{% hint style="info" %}
메뉴 경로: 시스템 설정 - 설정 홈 연결 - 일반 모듈 설정 - 내용검색
{% endhint %}

문서중앙화 솔루션의 검색은 2가지로 구분됩니다.

* 파일명 검색: 검색엔진 사용하지 않고, 서버엔진에서 파일명으로 검색
* 내용 검색: 별도 검색 엔진 사용
