# 파일 헤더 설정

{% hint style="info" %}
메뉴 경로: 시스템 설정 - 설정 홈 연결 - 고급 설정 - 파일 헤더
{% endhint %}

파일이 헤더를 갖도록 설정하여 추가적인 정보나 기능을 제공할 수 있습니다.

**내용검색, 문서태그, 문서보안등급, 문서 만료일** 등의 기능을 사용하기 위해서는 반드시 파일 헤더를 설정해야 합니다. 파일 헤더를 사용하는 경우에는 파일명 뒤에 **.cld+** 가 붙어서 저장됩니다.

{% hint style="warning" icon="square-poll-horizontal" %}
파일 헤더에 관한 자세한 내용은 [**문서함에 저장된 파일의 이름과 구조**](../../system/undefined-1/undefined-4.md)를 참고하세요 .
{% endhint %}
